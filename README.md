# Minecraft Cheeseburger Skin Texture

Cheeseburger Man is a Minecraft skin texture template in the standard 64x64 Steve-model UV layout, implemented as crisp pixel art with transparent unused areas, bold outlines, burger-themed colors, separate head, body, arm, and leg surfaces, and an overlay layer for raised sesame seeds, waist lettuce, and shoulder cheese details.

## Install

1. Download `assets/textures/cheeseburger_skin.svg`.
2. Convert the SVG to a 64x64 PNG while preserving crisp edges and transparency.
3. Open the converted PNG in a Minecraft skin editor or upload it through the Minecraft profile skin settings.
4. Select the classic or Steve player model if the game asks for a model type.

## Use

1. Apply the skin PNG to a Minecraft profile or import it into a compatible skin editor.
2. Keep nearest-neighbor or pixel-perfect scaling enabled when previewing or editing.
3. Do not resize the texture below or above the required 64x64 skin dimensions.
4. Keep transparent pixels transparent so unused UV areas remain empty.
5. Use the overlay layer to display the raised sesame seeds, waist lettuce frills, and shoulder cheese details.
